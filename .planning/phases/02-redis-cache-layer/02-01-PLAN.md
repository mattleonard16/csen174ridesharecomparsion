<feature>
  <name>getCached&lt;T&gt; L1+L2 wrapper and incrementQuotaCounter</name>
  <files>lib/cache/redis-cache.ts, __tests__/lib/cache/redis-cache.test.ts</files>
  <behavior>
    getCached<T>(key, ttlSeconds, compute):
    - L1 hit: L1 entry exists and not expired → return { value, cacheHit: true }, do NOT call compute, do NOT call redis
    - L2 hit: L1 miss, redis.get returns non-null → warm L1, return { value, cacheHit: true }, do NOT call compute
    - Full miss: L1 miss + L2 miss (redis.get returns null) → call compute, write to L1, fire-and-forget redis.set with { ex: ttlSeconds }
    - Redis null: redis is null → skip all L2 operations, still L1 check → compute on miss → store L1 only
    - Redis L2 read error: redis.get throws → swallow error, fall through to compute (same as full miss)
    - L1 eviction: when store.size >= L1_MAX_SIZES[namespace], evict expired entries first; if still over limit, evict first-inserted key (FIFO)
    - Logging: call log('Cache hit', { event: 'cache_hit', cacheKey: key, cacheLayer: 'memory'|'redis' }) on hits; log('Cache miss', { event: 'cache_miss', cacheKey: key, cacheLayer: 'memory' }) on miss before returning

    L1 namespace limits (extracted from key prefix before first ':'):
    - geocode: 500, route: 500, comparison: 200, rec: 200, ai: 100, default: 200

    incrementQuotaCounter(key: string): Promise<number>:
    - Calls redis.incr(key), returns the new count
    - On count === 1: calls redis.expireat(key, nextMidnightUTCUnixSeconds)
    - Redis null or any error: return 0 (fail-open, allows AI calls to proceed)
    - nextMidnightUTC: Date.UTC(year, month, date + 1) — always UTC, not local time

    clearCacheNamespace(namespace: string): void:
    - Clears the L1 Map for that namespace (if it exists)
    - Used by resetRideComparisonCaches() in ride-comparison.ts (Plan 02)
  </behavior>
  <implementation>
    Create lib/cache/ directory. Write tests first (RED). Then implement to pass (GREEN).

    Structure of lib/cache/redis-cache.ts:
    1. L1_STORES: Map<string, Map<string, CacheEntry<unknown>>> — namespace-keyed
    2. L1_MAX_SIZES: Record<string, number> object with per-namespace limits
    3. Internal helpers: getL1Store, extractNamespace, evictL1IfNeeded
    4. Export: getCached<T>(key, ttlSeconds, compute) → Promise<{ value: T; cacheHit: boolean }>
    5. Export: incrementQuotaCounter(key) → Promise<number>
    6. Export: clearCacheNamespace(namespace) → void

    The redis.set L2 write is fire-and-forget: call without await, chain .catch(() => {}).
    The redis.get L2 read IS awaited (it's on the hot path only when L1 misses).

    Mocking in tests: jest.mock('@/lib/redis', () => ({ redis: mockRedisObject, isRedisAvailable: true }))
    The mock redis object needs .get and .set and .incr and .expireat as jest.fn().
