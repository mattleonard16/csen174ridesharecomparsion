Make two changes to `jest.config.js`:

1. **Fix the typo on line 10:** Rename `setupFilesAfterSetup` to `setupFilesAfterEnv`. This is a one-character correction — the misspelled key is silently ignored by Jest, so `jest.setup.ts` never loads.

2. **Expand `collectCoverageFrom`:** Replace the current 3-entry array with the full set covering all authored code:

```javascript
collectCoverageFrom: [
  'app/api/**/*.{ts,tsx}',
  'components/**/*.{ts,tsx}',
  'lib/**/*.{ts,tsx}',
  'hooks/**/*.{ts,tsx}',
  '!**/*.d.ts',
  '!lib/generated/**',
  '!lib/prisma.ts',
],

```

The exclusions `!lib/generated/**` and `!lib/prisma.ts` are mandatory — omitting them causes Prisma-generated client files (hundreds of files with 0% coverage) to appear in the report, making overall coverage appear catastrophically low.

Do NOT add a `coverageThreshold` — there are no existing enforced thresholds and adding one now would fail CI on pre-existing untested code.
