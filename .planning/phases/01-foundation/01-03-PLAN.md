
```typescript

  log('Cache hit', { event: 'cache_hit', cacheKey, cacheLayer: 'memory' })

```

**Cache miss logs** — add immediately after the cache `set()` call at each write point:

For geocode:
```typescript
GEOCODE_CACHE.set(cacheKey, { value: coordinates, expiresAt: now + API_CONFIG.CACHE_TTL })
log('Cache miss', { event: 'cache_miss', cacheKey, cacheLayer: 'memory' })
```

Note: There are two geocode cache write paths (airport code path and Nominatim path). Add the miss log to BOTH. The airport code path is a valid geocode cache population, not a cache miss in the traditional sense — but for telemetry consistency, log it as a cache miss (initial population) there too.

For route cache:
```typescript
ROUTE_CACHE.set(routeCacheKey, { value: metrics, expiresAt: now + ROUTE_CACHE_TTL })
log('Cache miss', { event: 'cache_miss', cacheKey: routeCacheKey, cacheLayer: 'memory' })
```

For comparison cache:
```typescript
COMPARISON_CACHE.set(cacheKey, { value: core, expiresAt: now + ttl })
log('Cache miss', { event: 'cache_miss', cacheKey, cacheLayer: 'memory' })
```
